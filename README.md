# Huss Huss Huss

A clicker game: every click makes a fighter jab the air and shout HUSS.

Play it: https://lype3262.github.io/huss-huss-huss/

The leaderboard runs on Supabase. `supabase-setup.sql` creates the table and the
`submit_score` function; the project URL and public anon key go at the top of the
leaderboard section in `index.html`.
